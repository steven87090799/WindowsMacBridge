# WindowsMacBridge 0.6.0（build 52）

## 安裝與使用

1. 點兩下 DMG，先正常結束舊版，把 WindowsMacBridge.app 拖進「應用程式」取代，再開啟。
2. 預設「一般模式」：權限頁逐項列出輔助功能、輸入監控、螢幕錄製與選用的登入時啟動。先核准前兩項；需要截圖再核准螢幕錄製。每次只按一列，核准 WindowsMacBridge 後回來重新檢查；需要時正常結束並重開 App。綠燈必須經本版 App 的原生檢查，不以舊版同名開關作為依據。
3. 本機 App、Terminal 與 IDE 套用完整 Windows 相容快捷鍵：Ctrl+C／V／A／X、S／Z／Y／F、T／W 與文字導覽等；Terminal 的 Ctrl+C 有選取時複製、沒有選取時中斷；Ctrl+Shift+C 明確中斷。遠端 Windows 與 VM 保留 Ctrl 給 Windows 處理；Game、停用與暫停規則仍保持原按鍵。
4. Win+Shift+S 或 PrintScreen 框選後直接貼上圖片；⌘⇧3／⌘⇧4 也直接複製。成功後右下角顯示縮圖約 5 秒，點擊用系統快速查看放大，關閉後釋放；新截圖會取代舊縮圖。首次擷取可能要求螢幕錄製授權；這不是 HID／Root 授權。

一般模式不自動安裝背景元件、不連線 root XPC、不捕捉 IOHID、不啟用 Driver。App 使用 ad-hoc 簽章，更新可能需要重新核准目前版本；沒有 Apple 公證。不要為此關閉 Gatekeeper／SIP 或重設其他 App 的權限。

## 六項一般設定

| 項目 | 新安裝預設／操作 |
|---|---|
| Windows 模式總開關 | 開；統一控制 Windows 快捷鍵、Fn／Ctrl 交換、Finder 加強與截圖自動複製。關閉時暫停這些功能、保留子項設定。快捷鍵含複製、貼上、復原、儲存、分頁與文字導覽；Alt+Tab 使用 macOS 原生切換器。唯音守護與登入啟動各自獨立。 |
| MacBook 鍵盤模式 | 關；明確開啟才交換本機內建 Fn／Globe 與左 Ctrl。外接與 UC 虛擬鍵盤不交換。切換前放開所有按鍵。 |
| Finder 檔案操作加強 | 開；Ctrl+X→切資料夾→Ctrl+V 移動、F2 改名、Delete 垃圾桶。Shift+Delete 交由 Finder 原生「立即刪除」確認視窗決定，舊版明確停用永久刪除的設定保留。文字編輯／未知焦點不會盲刪；讀不到 Finder 焦點時 Ctrl+V 只做一般貼上，不搬移檔案。無需 Finder 擴充。 |
| Windows 快捷截圖 | 開；Win+Shift+S／PrintScreen 框選，Alt+PrintScreen 當前視窗，Win+PrintScreen 全螢幕存檔＋複製。⌘⇧3／⌘⇧4 使用相同取消／自動複製流程。 |
| 這臺 Mac 收到的 Windows 鍵 | Command；若實際 Win 發出 Option，改選 Option。不是交換整臺鍵盤的 Ctrl／Command。 |
| 開機自動啟動 | 使用系統原生登入項目，只有明確切換才註冊／移除；不因截圖開關而自動申請。 |

上方保留權限、一般設定、唯音與輸入法、App 規則；唯音守護與切換熱鍵預設關閉，關閉守護時保留原輸入來源。開啟守護後預設維持唯音繁體；如需英文，用 App 的 ABC 按鈕或切換快捷鍵明確選擇，這個目標會保存。系統或其他程式改變輸入來源不會更改守護目標；喚醒及解除暫停後會恢復目標。自訂 App／來源／裝置與明確關閉的功能設定保留；損壞設定安全停用，不覆寫原資料。

## 快捷鍵規則預覽

到「規則預覽」選擇 App、預覽 Profile 與按鍵來源，先看 Ctrl+C／Ctrl+Shift+C、Finder、瀏覽器、Alt+Tab、截圖等組合的預期輸出，也可選自訂組合。「模擬總開關開啟」只影響此頁，實際功能尚未啟用時也能預覽；不會改變已儲存的 App 規則、輸出按鍵或新增監聽。

Terminal 的 Ctrl+C 依選取狀態決定：有選取文字時複製，沒有選取時中斷命令；Ctrl+Shift+C 明確中斷。選取狀態無法確認時僅嘗試複製，不猜測中斷；Remote／VM 等受保護模式顯示原樣通過。來源欄表示抵達 Mac 的按鍵，已轉成 Mac 的遠端來源不重複翻譯，未知來源自動模式不猜測。預覽不代表已核准權限，也不模擬所有實體鍵盤／AX 焦點條件。

## 遠端來源校準

在 Windows 模式與必要權限啟用後，開啟「遠端校準」。先從遠端電腦送一個鍵到這台 Mac，確認來源列顯示「已觀察到此來源的輸入」，再按「開始校準」。保留設定視窗，切到這台 Mac 的 TextEdit 等文字 App，從指定遠端電腦按一次 Ctrl+C。App 只辨識這次 Control／Command 組合；60 秒內確認並套用結果，確認前原設定不變。

可取消、重新校準、手動指定來源按鍵或恢復自動判定；套用後可「還原校準前設定」。來源退出／重啟、暫停、Secure Input、權限或其他輸入政策改變都會取消未確認結果；正常本機 App 切換不會中斷測試。只偵測到遠端軟體不代表已收到輸入，也不代表所有連線組合已實機驗收。

## MacBook 與兩台 Mac

Mac mini 外接鍵盤固定不換；MacBook 只使用內建鍵盤，在 MacBook 開啟 Fn／Ctrl 模式，在 Mac mini 保持關閉。兩端都安裝 App、先使用一般模式，再按 [TwoMacAcceptance.md](TwoMacAcceptance.md) 分別測本機與 UC 兩方向。

原生映射使用 Apple 的 UserKeyMapping service properties；只修改本 App 擁有的 pair，保留其他工具。正常退出時先暫停輸入輔助，最多等待約 3 秒放鍵並確認還原；仍未還原會提供重試或取消結束，保留還原紀錄。關閉功能時也請放開所有按鍵。強制結束可能留下暫存映射，下次啟動依還原紀錄處理，重新開機清除服務暫存。喚醒與內建鍵盤重建會重新檢查。其他工具佔用 Fn／Ctrl 時顯示衝突，不覆蓋。

UC 與 Remote 不是相同來源契約，來源 PID／目標 App 可能缺失；不能承諾每種組合都通過。已知 Google CRD host 的 raw Ctrl 依 Mac 目的端轉成 Command；已是 Command 的事件通過。Mac 上開遠端 Windows viewer 時保持 Ctrl，不要把 viewer 的 App 規則改成 Default macOS。未知來源不猜。

## 截圖權限與取消

第一次明確擷取才可能提出螢幕錄製要求；到「隱私權與安全性 → 螢幕與系統音訊錄製 → WindowsMacBridge」開啟。AX 無法替代這項授權。一般權限頁直接列出螢幕錄製入口，截圖失敗也會在一般設定顯示原因。

一般截圖使用暫存 PNG，直接寫入 public.png 剪貼簿；縮圖關閉或快速查看結束後清除自己的暫存原圖。縮圖只保留最長邊 480 像素的小圖，未截圖時不建立視窗或固定輪詢。只有 Win+PrintScreen 明確保存全螢幕圖片到桌面，必要時由 macOS 要求該資料夾存取；已存檔的圖片不會隨縮圖消失而刪除。沒有監看整個桌面或 Finder `/`。Esc、Pause、功能關閉、backend／session／安全狀態改變會取消舊工作；只有當前一輪可寫入剪貼簿。同時最多一輪擷取，120 秒逾時；權限、程序、磁碟、解碼／編碼錯誤各自顯示。

## 截圖文字擷取

從選單列「截圖文字擷取…」或一般設定的「框選擷取文字…」選取畫面文字。需開啟 Windows 模式總開關與 Windows 快捷截圖，沿用螢幕錄製授權。Apple Vision 在本機辨識繁體中文與英文，完成後直接貼上文字；不會上傳或記錄內容，也不會替一般圖片截圖自動執行 OCR。Vision 放在獨立執行檔，只在要求辨識時啟動，工作結束退出；主程式不直接連結 Vision，也不預熱模型。辨識期間仍會使用 CPU／記憶體，macOS 層的快取由系統管理。

圖片擷取與文字擷取共用一個工作；可按取消，亦會遵守暫停、Session、安全輸入及權限變更。沒有文字、辨識失敗或過期結果不更動剪貼簿。辨識最多使用 2560 邊長／400 萬像素、64 KiB／1,000 行結果；超過時請縮小框選範圍。工作程序最多辨識 30 秒，首次模型準備可能較久，結束後釋放模型記憶體。小字或複雜多欄版面可能需要更小、更清楚的選區，貼上前請檢查重要文字。

## 選配進階模式

一般設定 → 展開「進階選項」→ 明確勾選「解鎖進階後端模式」。之後才顯示後端、安裝／移除、Driver、指定鍵盤及詳細診斷。勾選本身不自動提權；選 HID 後，用面板的安裝按鈕準備背景元件，再逐項核准輸入監控與 Driver。所有安裝材料仍在同一 App，不要另外找 HID Helper.app。

系統 Driver 的官方名稱是 `.Karabiner-VirtualHIDDevice-Manager`；沒有自己的 Developer／DriverKit 簽署資格不能冒用或改寫該名稱。共用 Driver 不會因為退出一般模式或移除 WindowsMacBridge 的 root runtime 被刪除。切回一般模式先釋放硬件 ownership／關閉 XPC；舊 HID 確認停止之前，兩種後端都不翻譯，最多等 3 秒。只有背景元件回覆已停止、該連線從未擷取，或背景元件確定已結束，才算釋放；連線中斷或在期限內沒有回覆時，App 不推定鍵盤已釋放：選單顯示「Helper 未確認釋放鍵盤」，確認鍵盤正常後按「恢復／重啟引擎」。緊急暫停組合 Ctrl+Option+Command+P 會立即交還實體鍵盤。HID 斷線／Driver teardown 仍需實機驗收。

暫停可用選單列；暫停與正常退出會取消輸入輔助及未完成截圖。診斷只在進階模式明確開啟，5 分鐘到期，記錄規則／時間，不記錄輸入文字。
