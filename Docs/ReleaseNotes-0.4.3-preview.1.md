# WindowsMacBridge 0.4.3 Preview 1

此版本加入預設開啟的「截圖自動複製」。按 `⇧⌘4` 仍可使用 macOS 框選截圖；完成後圖片照常儲存，也會複製到剪貼簿，供 `⌘V` 貼上。開關可在「一般與權限 → 截圖」關閉。已明確關閉的設定會在更新後保留。

- 開啟時立即檢查截圖配置，之後每 30 天檢查與修復，並在本機保留有界診斷日誌。
- 診斷頁新增版本、Build、UTC 編譯時間、Git commit、原始碼狀態與 Bundle ID；也可用 `--version` 查看。
- 更新了設定頁、操作說明及測試；主套件與 HID helper 的離線測試已通過。

下載 DMG、核對 SHA-256 後，先從 Menu Bar 結束舊版，再將 App 拖到 `/Applications` 替換，從該位置啟動。此包是 ad-hoc 簽署的 Apple Silicon 預覽版；若 macOS 要求重新核准輔助使用、截圖或登入項目，請在系統設定核准。目前離線測試不等於實機截圖與貼上驗收。
